# 이미지 검수 후보

`banana-candidate.png`: Aside 이미지 생성 도구로 실제 생성한 '먹는 과일 바나나' 사진형 시안.
이 파일은 생성에 성공한 검수 **후보**이며, 임상 검증·당사자 이해도 확인·공용 라이브러리 승인을 받지 않았습니다.
기본 카드에 자동 적용하지 않았고, `server/library/approved.json`에 등록하지 않았습니다.
Aside 이미지 생성 도구의 성공은 앱의 OpenAI API 연결 성공을 의미하지 않습니다.

확인 기준: 글자 없이 구체적 대상을 구별하는가, 48~96px에서도 주요 형태가 보이는가,
다른 과일·대상과 혼동되지 않는가, 실제 AAC 사용자가 뜻을 이해하는가.

공용 등록은 뜻·종류·검수자·검수일을 기록하고 `server/README.md`의 절차를 따라 별도로 수행합니다.
